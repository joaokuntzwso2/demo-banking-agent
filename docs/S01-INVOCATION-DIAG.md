# Banco Aurora S01 — specialist invocation diagnosis

This is an additive, diagnostics-only package. It uses `scripts/diagnose-aurora-chat.py` from Chat Diagnostics v1 for loopback-only Kubernetes port-forward and private Portal login. It issues one synthetic S01 chat request and reports only allowed role names, error type classes, action types and baseline indicators. It does not approve or execute operations, reset Core, modify Kubernetes, or rotate keys. **It can create pending synthetic approvals** if specialist execution works.

Run `python3 scripts/diagnose-aurora-s01.py`. If Card and Dispute were invoked but report `ConnectError`, inspect the injected `AGENT_CARD_URL`/`AGENT_DISPUTE_URL` published gateway routing: Concierge uses their URLs verbatim inside Kubernetes (unlike Portal's in-cluster gateway adaptation). Do not bypass the authenticated gateway. If `HTTPStatusError`, distinguish agent call authorization vs upstream tool access using sanitized logs. If both returned without errors but no approvals, inspect action intent, synthetic card/transaction selection and clarified intent. A full S01-S06 regression still requires the runner, with its state reset, after resolving the failure.
